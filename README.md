# Portfolio — Jules Claurèce Kagbahinto

Portfolio personnel de développeur Full-Stack, présentant mon parcours, mes compétences et mes projets.

🔗 **Site live** : [jules-claurece-dev-portofolio.vercel.app](https://jules-claurece-dev-portofolio.vercel.app/)

## Aperçu

Site vitrine one-page construit avec React et Vite : présentation, compétences techniques (avec une animation d'orbites), projets réalisés et moyens de contact.

## Stack technique

- [React 19](https://react.dev/)
- [Vite](https://vite.dev/)
- CSS plain (un fichier par composant, pas de framework CSS)
- [ESLint](https://eslint.org/) (flat config)

## Structure du projet

```
src/
├── components/       # Header, Hero, About, Skills, Projects, Contact, Footer
├── data/             # Données statiques (liste des projets)
└── assets/           # Images et icônes
```

## Lancer le projet en local

```bash
npm install
npm run dev
```

Le site est alors disponible sur `http://localhost:5173`.

## Autres commandes

```bash
npm run build    # Build de production
npm run preview  # Prévisualiser le build de production
npm run lint     # Vérifier le code avec ESLint
```
